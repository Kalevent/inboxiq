# Understanding Outlook categories

In Outlook, InboxIQ uses **categories** (the coloured tags built into Outlook) instead of labels. They appear as coloured chips on each email row in your inbox.

## How categories differ from Gmail labels

| | Gmail | Outlook |
|---|---|---|
| Appear in sidebar | ✅ Yes — as collapsible group | ❌ No sidebar grouping |
| Click to filter | ✅ Yes | Requires search or filter |
| Colour | ✅ Custom hex colours | Named preset colours |
| Nested structure | ✅ InboxIQ/Support/Urgent | ✅ Displayed as text |

## Filtering by category in Outlook

To see all emails in a category:
1. Use the **Filter** button above the email list → **By category**.
2. Or use Outlook's search bar and filter by category name.

## Changing a category

If InboxIQ applied the wrong category:
1. Right-click the email in your inbox.
2. Select **Categorize**.
3. Choose the correct `InboxIQ/` category.

InboxIQ detects the change on the next poll and records a correction.
