# What happens if I disconnect my inbox?

Disconnecting an inbox stops InboxIQ from polling it. Here is exactly what changes — and what stays the same.

## What stops immediately

- InboxIQ stops reading new emails from the disconnected inbox
- No new labels are applied in Gmail / categories in Outlook
- No new AI draft replies are created for that inbox

## What stays in place

- **Labels and categories already applied** remain in Gmail and Outlook. InboxIQ does not remove labels it has already created when you disconnect.
- **Automation rules** you set up are saved in InboxIQ. They resume working if you reconnect the same inbox later.
- **Knowledge base and triage settings** are not affected.
- **Your InboxIQ account** remains active — other connected inboxes continue working normally.

## Drafted replies already in Gmail/Outlook

Any drafts InboxIQ already saved in Gmail or Outlook Drafts remain there. Disconnecting does not delete them.

## Reconnecting later

You can reconnect the same inbox at any time from **Settings → Inboxes**. InboxIQ picks up from where new emails start arriving — it does not retroactively process emails that arrived while disconnected.
