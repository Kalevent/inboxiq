# Will my teammates see each other's emails?

**No.** InboxIQ keeps each inbox completely private.

## How inbox isolation works

When you invite a teammate to connect their inbox, each inbox is processed independently. InboxIQ does not create a shared view of everyone's emails.

- Teammate A cannot see emails from Teammate B's inbox
- Teammates cannot see each other's draft replies
- Each person's labels and categories are applied only in their own Gmail or Outlook account

## What is shared across the team

The only things shared at the account level are:

- **Automation rules** — rules created by the account owner apply to all connected inboxes unless scoped to a specific inbox
- **Triage settings** — the label/category set and confidence threshold apply account-wide
- **Knowledge base content** — the AI context you upload in Settings applies to all inboxes on the account

## Admin visibility

Account owners can see which inboxes are connected and their connection status (connected/disconnected). Account owners cannot read the emails in a teammate's inbox through InboxIQ.
