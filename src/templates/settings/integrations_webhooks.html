Configure webhook / Intake API

Use this endpoint to send forms, chat handoffs, CRM events, or internal tool requests into InboxIQ for triage. Full docs: /docs/intake_api

Endpoint
POST {{ request.url_root.rstrip('/') }}/api/v1/intake
Auth
  • X-Intake-Token header (per-account token generated below; stored hashed).
  • Or logged-in JWT (for in-app usage).
Status: {% if intake_token_set %}active tokens exist{% else %}no active tokens{% endif %}.
Example payloads
{
  "subject": "Contact us: integration question",
  "body": "How do we connect our internal CRM to InboxIQ?",
  "source": "form"
}
            
{
  "subject": "Chat handoff: billing issue",
  "body": "User: I was double-charged...\nBot: Let me check...\nUser: please escalate.",
  "source": "chat"
}
            
{
  "subject": "CRM: escalated lead responded angrily",
  "body": "Lead ABC replied: \"Why was I charged again?\"",
  "source": "crm",
  "provider_thread_url": "https://crm.example.com/leads/abc"
}
Sample curl
curl -X POST "{{ request.url_root.rstrip('/') }}/api/v1/intake" \
  -H "X-Intake-Token: $INBOXIQ_INTAKE_TOKEN" \
  -H "X-Timestamp: $(date +%s)" \
  -H "X-Signature: " \
  -H "Content-Type: application/json" \
  -d '{
    "subject": "Contact us: integration question",
    "body": "How do we connect our internal CRM to InboxIQ?",
    "source": "form"
  }'
