{# ── How It Works ──────────────────────────────────────────── #}
How It Works

The email is the trigger. No webhook setup required.

1

Stripe sends a payment email

A Stripe payment confirmation lands in your connected Gmail or Outlook inbox. InboxIQ classifies it as a transaction automatically — no rules to write.

2

Finance Add-on extracts the data

The add-on reads amount, date, customer, and reference from the email. No parsing configuration needed — InboxIQ understands Stripe's email format out of the box.

3

QuickBooks gets the entry

In Direct sync mode the transaction posts to QuickBooks via the API immediately. In CSV export mode an Intuit-compatible CSV lands in your inbox every Monday — import in two clicks.

{# ── FAQ ───────────────────────────────────────────────────── #}
FAQ

Common questions

Do I need to configure a Stripe webhook?

No. InboxIQ reads the payment confirmation email Stripe already sends to your inbox. There is no webhook endpoint to set up or maintain.

Which QuickBooks versions are supported?

Direct sync uses the QuickBooks Online API. CSV export is compatible with QuickBooks Online and QuickBooks Desktop via the Import Data feature.

Can I switch between Direct sync and CSV export?

Yes. Click Reconfigure on the Finance Add-on page, select the new mode, and submit. The change takes effect immediately.

Which plan includes the Finance Add-on?

Business and Enterprise plans. Starter and Pro accounts see the Finance Add-on section with an upgrade prompt.
