{# ── How It Works ──────────────────────────────────────────── #}
How It Works

Register, push, get back a decision

1

Register your app

Create a registered app under Settings → Developer. You get a client_id and client_secret for HTTP Basic Auth. No OAuth dance for server-to-server calls.

2

POST to the Intake API

Send a JSON payload to /api/v1/intake with your subject, body, and sender fields. The same triage pipeline that handles email runs on your payload.

3

Decision returned in response

The API returns the triage result — intent, urgency, assigned labels, and routing outcome — synchronously. Your system can act on the decision immediately.
