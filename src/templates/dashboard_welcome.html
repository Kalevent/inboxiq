WhatsApp Webhook Setup

Step 1 — Create a Developer App

Go to Settings → Developer, create an app with the intake:write scope, and copy your Client ID and Client Secret.

Step 2 — Configure the Webhook URL

Set your platform webhook destination to:

https://hook.kalevent.com/api/v1/intake

Step 3 — Add Authentication Header

In your platform's webhook settings, add an HTTP header:

Authorization: Basic <base64(client_id:client_secret)>

See Channel Intake Guide for platform-specific instructions.

InboxIQ Native Chat Widget

A beautiful, lightweight chat widget that captures visitor information and routes conversations to your InboxIQ triage pipeline.


<script>
  (function(w,d,s){
    w.InboxIQ=w.InboxIQ||{};
    w.InboxIQ.account='{{ account_id or "YOUR_ACCOUNT_ID" }}';
    w.InboxIQ.config={welcomeMessage:'Hi! How can we help you today?',captureLeads:true,requireEmail:true};
    var f=d.getElementsByTagName(s)[0],j=d.createElement(s);
    j.async=true;j.src='https://kalevent.com/static/js/chat-widget.js';
    f.parentNode.insertBefore(j,f);
  })(window,document,'script');
</script>

Copy this code and paste it before the closing </body> tag on your website.

Webhook Setup

Step 1 — Create a Developer App

Go to Settings → Developer, create an app with the intake:write scope, and copy your Client ID and Client Secret.

Step 2 — Configure the Webhook URL

In your chat platform's webhook settings, set the destination URL to:

https://hook.kalevent.com/api/v1/intake

Step 3 — Add Authentication Header

Add an HTTP header to every outgoing webhook request:

Authorization: Basic <base64(client_id:client_secret)>
