# Outreach Video Programme — Design Spec

**Date:** 2026-05-04
**Status:** Approved

---

## Goal

Send high-fit, warm non-responders a personalised video as the final step in the outreach email sequence. The video script is generated by DSPy using stored Lead data plus a fresh intent signal fetch. Delivered by email. A public LinkedIn teaser post goes out when each delivery batch runs.

---

## Trigger

The programme is **campaign-scoped**. It only fires for `EmailCampaign` records that have `outreach_video_enabled = True`. A new boolean column is added to `EmailCampaign`.

A daily beat task `queue_outreach_videos()` scans eligible campaigns and finds leads that meet all of the following criteria:

| Criterion | Source |
|---|---|
| `EmailOutreach.sequence_step = 2` exists for the lead | Second follow-up has been sent |
| No `replied_at` on any `EmailOutreach` for this lead | Lead has not replied |
| `EmailOutreach.open_count >= 1` on at least one row | Lead opened at least one email |
| `Lead.fit_score >= 7` | High ICP fit |
| No existing `OutreachVideo` for this `(account_id, lead_id)` | Idempotency guard — one video per lead |

A daily cap (`OUTREACH_VIDEO_DAILY_LIMIT`, default 20) prevents unexpected HeyGen spend.

---

## Personalisation Inputs

| Field | Source |
|---|---|
| `recipient_name` | `Lead.name` |
| `recipient_company` | `Lead.company_name` |
| `industry` | `Lead.industry` |
| `intent_signals` | Fresh `detect_intent_signals(company_domain)` call at generation time |
| `pain_point` | Derived from `Lead.industry` + `Lead.fit_score` breakdown |

If `detect_intent_signals()` fails or the lead has no `company_domain`, the script falls back to stored Lead fields only — no hard failure.

---

## DSPy Signature

A new `OutreachVideoScript` signature added to `src/dspy/signatures.py` via `build_outreach_signatures(dspy)`:

**Inputs:** `recipient_name`, `recipient_company`, `industry`, `intent_signals`, `pain_point`

**Outputs:** `script`, `hook_line`, `cta_line`, `subject_line`

The script covers three beats:
1. **Hook (10s)** — opens with the fresh intent signal: *"I noticed [Company] is hiring a VP of Operations — that usually means…"*
2. **Pain + solution (40s)** — connects the signal to the inbox overload problem InboxIQ solves
3. **CTA (10s)** — one ask: reply to the email or book a 15-min call

`subject_line` is stored on `VideoRender` and used as the email subject when the video is delivered.

The compiled module is persisted to `dspy_artifacts/outreach_video_script.json` with HMAC signing, following the existing `dspy_artifacts/` pattern.

## Task Architecture

### Task 1: `queue_outreach_videos` (daily beat, 8:00am)

**File:** `src/tasks/outreach_video.py`
**Queue:** `"content"`
**Env var guard:** `OUTREACH_VIDEO_ENABLED`

Steps:
1. Query all `EmailCampaign` records where `outreach_video_enabled = True`
2. For each campaign, run the lead selection query (criteria above), capped at `OUTREACH_VIDEO_DAILY_LIMIT`
3. For each eligible lead:
   a. Call `_run_outreach_script_generation(lead)` — fetches intent signals, runs DSPy
   b. Create `VideoRender(programme="outreach", video_style="avatar", aspect_ratio="16:9", script=..., subject_line=...)`
   c. Create `OutreachVideo(account_id, lead_id, video_render_id)`
   d. Flush, commit with try/except rollback
   e. Submit to HeyGen via `heygen_mcp.render_video(script, avatar_id, voice_id, video_format="mp4", aspect_ratio="16:9")`
   f. Set `render.heygen_job_id`, `render.status = "rendering"`, `render.render_submitted_at`
   g. Commit

The generic `/api/v1/heygen/webhook` handles the HeyGen callback and sets `render.status = "render_complete"` — no new webhook code needed.

---

### Task 2: `deliver_outreach_videos` (daily beat, 9:30am)

**File:** `src/tasks/outreach_video.py`
**Queue:** `"content"`
**Env var guard:** `OUTREACH_VIDEO_ENABLED`

Steps:
1. Query `OutreachVideo JOIN VideoRender` where `render.status = "render_complete"` AND `outreach_video.delivered_email_at IS NULL`
2. For each row: call `send_outreach_video_email(to_email, recipient_name, video_url, subject)` where `subject = render.subject_line`
3. Set `outreach_video.delivered_email_at = now()`
4. Commit with try/except rollback per row
5. After all rows: if `sent >= 1`, call `post_outreach_video_to_linkedin(account_id)` once per account

---

### Task 3: `post_outreach_video_to_linkedin` (triggered from Task 2)

**File:** `src/tasks/outreach_video.py`

Posts a single public teaser post via the account's stored LinkedIn OAuth token using the existing `_post_to_linkedin` pattern from `src/marketing/content_distribution.py`. One post per delivery run, not per lead.

Example text: *"Sending personalised video outreach this week — if you're a B2B SaaS founder dealing with inbox overload, expect a personal video from me."*

Only fires if a LinkedIn OAuth connection (`linkedin_social` provider) exists for the account.

## Email

**New function:** `send_outreach_video_email(to_email, recipient_name, video_url, subject)` in `src/notifications/emails.py`

Follows the exact same SMTP/SES pattern as `send_onboarding_video_email`. Subject is the DSPy-generated `subject_line`. Body includes a prominent CTA button ("Watch your personalised video →") linking to `render.heygen_render_url` (opens in new tab), HTML body fields HTML-escaped before rendering, and a plain-text fallback URL.

---

## Model Change

**`EmailCampaign`** gains one new column:
- `outreach_video_enabled` (Boolean, default False, nullable=False)

No changes to `OutreachVideo` — the existing model has everything needed:
- `account_id`, `lead_id`, `video_render_id`
- `delivered_email_at` (set on email send)
- `delivered_linkedin_at` (reserved — not used in this plan)

## What's Explicitly Out of Scope

- LinkedIn DMs per lead — `delivered_linkedin_at` column reserved for future LinkedIn Messaging API access
- Re-queuing leads who were previously sent a video (one video per lead, guarded)
- Video thumbnail generation (link only, no custom thumbnail)
- In-app video player / embedding (CDN link opens in new tab)
- Tracking video views (HeyGen CDN link, no pixel tracking)
