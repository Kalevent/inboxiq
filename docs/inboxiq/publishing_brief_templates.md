# Publishing Brief Templates (Internal)

Use these prompts as staff-facing templates to give the Publishing Agent clear inputs. All are SEO-oriented and tuned for support/ops leadership audiences. Fill in the bracketed fields before sending to the agent.

## Blog (SEO short article)
- Title: `[Clear, keyword-focused title]`
- Audience: `Support and ops leaders in [industry/segment]`
- Brief:  
  - Goal: `Explain/argue/show how [core idea]`  
  - Keywords: `[primary keyword], [secondary keyword 1], [secondary keyword 2]`  
  - ICP: `[1–2 lines on who we’re talking to]`  
  - Problem: `They struggle with [pain], which causes [impact]`  
  - Our POV: `We believe [differentiated stance]`  
  - Proof: `Use data/metrics: [insert any stats, benchmarks, case study notes]`  
  - CTA: `Book a demo to see [specific capability]`
- Tone/style: `Direct, confident, plain language; short paragraphs; scannable subheads; include a numbered or bulleted list; one strong CTA near the end.`
- Length: `600–900 words`

## Newsletter (email)
- Campaign title: `[e.g., December Ops Brief]`
- Audience: `[segment/persona]`
- Brief:  
  - Theme: `Top insight: [one-liner]`  
  - Sections (3–4): `[bullets for each section with key point + link target if any]`  
  - Offer/CTA: `Book a demo / Download guide / Join webinar`  
  - Compliance: `Keep inline CSS-light HTML; mobile-friendly; 600–680px width; include unsubscribe/footer copy`
- Tone/style: `Concise, helpful, skimmable; subject line variants; clear preheader.`

## Whitepaper (long-form)
- Title: `[Working title]`
- Audience: `[decision-makers: ops/support leaders, IT, procurement]`
- Brief:  
  - Problem: `[2–3 sentences on current state/pain]`  
  - Scope: `Explain [system/process], include [frameworks, KPIs, benchmarks]`  
  - Our POV: `[thesis]`  
  - Evidence: `Include data: [metrics/case studies/benchmarks], cite sources`  
  - Architecture/Approach: `Describe how we solve it (workflow, integrations, controls)`  
  - ROI: `Provide assumptions/table if possible`  
  - CTA: `Book a demo / Talk to an expert`
- Tone/style: `Authoritative, plain English, evidence-first; Markdown with clear headings; avoid fluff.`
- Length: `6–12 pages equivalent`

## Tips to improve outputs
- Always supply concrete inputs: audience, pain, POV, proof points, CTA.
- Include target keywords and a sample CTA link.
- For SEO: set a clear primary keyword and a natural H1/H2 structure.
- For edits: add “feedback” notes and regenerate; publish only after human review.
